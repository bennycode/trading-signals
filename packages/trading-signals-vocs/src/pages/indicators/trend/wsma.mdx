# Wilder's Smoothed Moving Average (WSMA)

Similar to RMA, this is a smoothed moving average that reduces noise and provides a clearer view of the trend.

## Usage

```ts twoslash
import {WSMA} from 'trading-signals';

// WSMA yields results once 5 inputs have been added
const wsma = new WSMA(5);
```
