# Relative Moving Average (Wilder's MA) (RMA)

Developed by J. Welles Wilder Jr., this smoothed moving average gives more weight to historical data, resulting in a smoother line.

## Usage

```ts twoslash
import {RMA} from 'trading-signals';

// RMA yields results once 5 inputs have been added
const rma = new RMA(5);
```
