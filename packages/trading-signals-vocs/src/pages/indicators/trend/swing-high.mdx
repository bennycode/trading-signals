# Swing High Detector (SwingHigh)

Detects symmetric pivot highs (fractal pivots). A candle is confirmed as a swing high once the configured number of candles on each side print strictly lower highs. Commonly used to mark resistance and breakout targets.

## Usage

```ts twoslash
import {SwingHigh, SwingLookback} from 'trading-signals';

// SwingHigh yields results once 5 inputs have been added
const swingHigh = new SwingHigh({lookback: SwingLookback.BILL_WILLIAMS});
```
