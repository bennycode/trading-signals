# Weighted Moving Average (WMA)

Assigns linearly increasing weights to recent data points. The most recent price has the highest weight.

Pick a market regime to see how WMA(5) reacts:

## Usage

```ts twoslash
import {WMA} from 'trading-signals';

// WMA yields results once 5 inputs have been added
const wma = new WMA(5);
```
