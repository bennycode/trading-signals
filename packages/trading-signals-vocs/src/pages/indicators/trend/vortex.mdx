# Vortex Indicator

Tracks upward and downward trend movement as two lines normalized by the true range. The upper line names the side in control; a crossover of VI+ and VI− suggests a trend change.

## Usage

```ts twoslash
import {VortexIndicator} from 'trading-signals';

// VortexIndicator yields results once 15 inputs have been added
const vortexIndicator = new VortexIndicator(14);
```
