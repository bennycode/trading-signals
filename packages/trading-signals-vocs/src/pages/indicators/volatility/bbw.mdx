# Bollinger Bands Width (BBW)

Measures the width between the upper and lower Bollinger Bands relative to the middle band. Useful for identifying squeezes and potential breakouts.

## Usage

```ts twoslash
import {BollingerBands, BollingerBandsWidth} from 'trading-signals';

// BollingerBandsWidth yields results once 20 inputs have been added
const bollingerBandsWidth = new BollingerBandsWidth(new BollingerBands(20, 2));
```
